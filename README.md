# D1 - Sistema de Mensajería 💬

Proyecto de maquetación de una interfaz de mensajería y contactos, desarrollado como parte del desafío del curso de Desafío Latam.

## Descripción

Layout de un sistema de mensajería que permite visualizar contactos y comenzar nuevas conversaciones. La pantalla está dividida en dos secciones principales: una barra lateral de contactos y una sección principal de bienvenida.

## Contenido

- Barra lateral con lista de contactos (foto + último mensaje)
- Estado del usuario con íconos
- Botón "Nuevo Chat"
- Sección principal con imagen y mensaje de bienvenida

## Tecnologías utilizadas

- **HTML5** — estructura semántica del proyecto
- **CSS3** — estilos y diseño visual
  - **Flexbox** — utilizado para posicionar y alinear todos los elementos de la página
  - **Google Fonts** — tipografías Roboto y Open Sans
  - **Font Awesome** — íconos de la interfaz
